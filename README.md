NeuraCET is bringing a live RAG-powered assistant to Drishti 2026! Running as an interactive, fully offline kiosk alongside the AI Summit across the CET campus, this assistant is designed to answer any question about the festival—pulled straight from official event data.

Whether you need to find a venue, check event timings, or look up historical Drishti context, the Drishti RAG Assistant provides instant, accurate answers using a lightweight, locally hosted LLM.

## Key Features

- **Instant, Offline Information:** Get real-time answers regarding Drishti schedules, venues, specific events, and timings without relying on an internet connection.
- **Powered by Qwen:** Utilizes a highly efficient open-weight model optimized for fast on-device inference.
- **Multi-Year Knowledge Base:** The retrieval system is loaded with structured data from Drishti **2022, 2024, and 2026** to provide comprehensive context and comparisons.
- **Kiosk-Optimized:** Built for a robust, low-latency deployment at the NeuraCET booth during the AI Summit.
- **Accurate & Hallucination-Resistant:** The bot strictly grounds its generation in the official documents provided in the vector database.

## Architecture & How It Works

1. **Data Ingestion:** Official schedules, rulebooks, and event details (2022–2026) are processed and chunked.
2. **Vector Storage:** Text chunks are embedded and stored in a local vector database for rapid similarity search.
3. **Retrieval:** When a user asks a question at the kiosk, the system queries the vector database for the most relevant context.
4. **Local Generation:** The context and the user's query are passed to the **local Qwen model** (served via Ollama), which generates a concise, accurate response tailored to the festival goer.

## Getting Started

### 1. Install Prerequisites

You will need **Python 3.9+** and **Ollama** installed on your machine to serve the local Qwen model. Download Ollama from [ollama.com](https://ollama.com).

### 2. Pull the Qwen Model

Open your terminal and run the following command to download the model via Ollama.

```bash
ollama run qwen
```

### 3. Set Up the Environment

Clone the repository and sync the dependencies. `uv` will automatically create a virtual environment and install everything defined in the `pyproject.toml`.

git clone https://github.com/your-username/drishti-rag-assistant.git
cd drishti-rag-assistant
uv sync

### 4. Load the Data

Place the official Drishti text files, CSVs, or PDFs into the `data/raw/` directory. Run the ingestion script to populate your local vector database.

### 5. Run the Kiosk Application

Ensure Ollama is running in the background, then start the main application using `uv run`, which automatically uses the correct virtual environment:

uv run main.py

### 6. Run the Kiosk UI

Open a second terminal window, navigate to the frontend directory, and start the development server:

```bash
cd ui
npm install
npm run dev
```
